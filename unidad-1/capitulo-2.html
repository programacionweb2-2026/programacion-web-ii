Capítulo 2. Introducción al Framework DJANGO

1. Introducción

Django es el framework basado en Python que se utilizará para avanzar desde la arquitectura conceptual hacia la implementación de una aplicación web completa.

2. ¿Qué es Django?

Django es un framework web de alto nivel escrito en Python. Proporciona componentes, convenciones y herramientas reutilizables, pero no reemplaza Python ni las decisiones de análisis y diseño.

3. Breve historia

Django surgió de la necesidad de reutilizar soluciones para problemas recurrentes del desarrollo web y fue publicado como proyecto de código abierto en 2005.

4. DRY y desarrollo rápido

El principio DRY —Don’t Repeat Yourself— busca evitar duplicaciones innecesarias. Django facilita el desarrollo rápido mediante componentes integrados, sin que ello implique desarrollo improvisado.

5. “Batteries included”

Django incluye URL Dispatcher, Views, Models + ORM, Templates, Forms, Authentication, Permissions, Django Admin, mecanismos de seguridad y herramientas de testing.

6. ORM

El Object Relational Mapper permite trabajar con datos mediante objetos Python y reduce la necesidad de escribir SQL directamente para numerosas operaciones.

7. Administración, autenticación y autorización

Django Admin facilita tareas administrativas. La autenticación responde quién es el usuario; la autorización determina qué puede hacer.

8. Seguridad y modularidad

Django incorpora mecanismos frente a riesgos frecuentes y favorece una organización modular mediante aplicaciones.

9. Proyecto y aplicación Django

El proyecto representa la configuración global de la solución. Una aplicación concentra funcionalidades relacionadas y puede contener modelos, vistas, rutas, formularios, templates y pruebas.

10. Entorno de trabajo

El material introduce entorno virtual, instalación de Django, creación del proyecto, aplicaciones, servidor de desarrollo y archivo de dependencias.

django-admin startproject mi_proyecto
python manage.py runserver

11. Primera evidencia práctica

Cada grupo debe contar con entorno virtual, Django instalado, proyecto funcionando, al menos una aplicación, servidor de desarrollo, archivo de dependencias y una propuesta inicial de organización del Trabajo Integrador.

12. Validación conceptual

El estudiante debe poder explicar qué problema resuelve un framework, diferencia entre Python y Django, DRY, proyecto y aplicación, manage.py, settings.py, urls.py, entornos virtuales, requirements.txt y runserver.
